⚔️ 经典对比（高频陷阱）

temperature vs top_p
temperature 管分布「尖锐程度」；top_p 管候选「范围」——题目常互换偷换概念
微调 vs 蒸馏
LoRA 需要标注数据；蒸馏需要教师模型——「需要教师模型权重」是蒸馏特征不是 LoRA
白盒 vs 黑盒蒸馏
白盒学软标签（暗知识）精度高、需教师权重；黑盒只需 API 输出
Function Calling vs MCP
FC = 模型调用能力；MCP = 工具接入标准协议——互补不互替
短期 vs 长期记忆
短期 = 上下文窗口；长期 = 向量库持久化检索——不是 RAM vs 硬盘
分层规划 vs 共创协作
顺序依赖链（大纲→代码→文稿）→ 分层规划；无明确分工边界 → 共创
Recall vs Precision
Recall=找得全（漏没漏）；Precision=排得好（顺序差）
compress vs clear
compress 压缩保留关键信息；clear 全部清空——75% 用量选 compress
提示词引导 vs max_tokens
要语义完整的简短回答 → 提示词引导优先，max_tokens 兜底
